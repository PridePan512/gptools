# 快速量价阈值设置

日期：2026-09-07  
范围：设置里可改四个「快速」条件的阈值。时间窗口、规则存储、添加条件界面不变。

## 目标

用户在设置里用百分数调整快速放量 / 缩量 / 拉升 / 下跌的灵敏度。全局一份，所有规则共用。未改过的行为和现在写死的阈值一致。

## 非目标

- 不开放时间窗口（间隔的 0.5～2 倍）
- 不做成每条规则各自一套阈值
- 不改涨停、穿越等其它比较符
- 不把成交额当量

## 百分数口径

界面和存储都用百分数，求值时除以 100：

| 项 | 默认 | 求值 |
| --- | --- | --- |
| 快速放量 | 200 | 本口速率 ≥ 上一口 × 2.00 |
| 快速缩量 | 50 | 本口速率 ≤ 上一口 × 0.50 |
| 快速拉升 | 1 | 折算后涨幅 ≥ 1% |
| 快速下跌 | 1 | 折算后跌幅 ≥ 1% |

可填小数，例如放量 `150`、拉升 `0.8`。空、非数字、≤ 0：该项回退默认。

## 设置界面

现有设置对话框加可滚动四项，hint 为「快速放量（%）」等。打开时填入已保存百分数。

检测进行中：间隔仍禁用；四个阈值可改，确定后立即持久化，下一口求值生效。确定按钮检测中也可用。取消不写回。

## 数据与求值

`RapidAlertThresholds` 持有四个百分数。`SortModeStore` / SharedPreferences 与间隔一起持久化。`AlertEvaluator.evaluate` / `isSatisfied` 增加该参数，默认即上表。`QuoteMonitor` 把当前阈值传入求值。

不改 Room、条件句式、通知详情格式。

## 测试

- 解析：合法百分数、空/非法/≤0 回退默认。
- 求值：默认下旧用例仍过；拉升改成 2% 时 1% 不再触发；放量改成 300% 时两倍不再触发。
- 保存阈值写入 store，检测中也可保存。
